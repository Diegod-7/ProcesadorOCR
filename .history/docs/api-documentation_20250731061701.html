Carné Aduanero

Procesamiento de carnés aduaneros desde archivos PNG y PDF

POST /api/CarnetAduanero/procesar PNG

Procesa un archivo PNG de carné aduanero y extrae todos los datos

Parámetros

file (IFormFile) - Archivo PNG del carné aduanero

Ejemplo de Request

curl -X POST "https://procesadorocr.onrender.com/api/CarnetAduanero/procesar" \
  -H "accept: text/plain" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@6.carne.png;type=image/png"

POST /api/CarnetAduanero/procesar-lote PDF

Procesa múltiples archivos PDF de carnés aduaneros en lote

Parámetros

files (IFormFileCollection) - Colección de archivos PDF

Ejemplo de Request

curl -X POST "https://procesadorocr.onrender.com/api/CarnetAduanero/procesar-lote" \
  -H "accept: text/plain" \
  -H "Content-Type: multipart/form-data" \
  -F "files=@carnet1.pdf" \
  -F "files=@carnet2.pdf"
POST /api/CarnetAduanero/procesar-texto-ocr TEXT

Procesa texto OCR extraído manualmente

Parámetros

textoOcr (string) - Texto extraído del documento

Ejemplo de Request

curl -X POST "https://procesadorocr.onrender.com/api/CarnetAduanero/procesar-texto-ocr" \
  -H "accept: text/plain" \
  -H "Content-Type: application/json" \
  -d '{
    "textoOcr": "CARNÉ ADUANERO N° 123456789..."
  }'
