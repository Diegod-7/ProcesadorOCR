# 🚀 ProcesadorOCR con DeepSeek R1: 8B + Ollama

## 🎯 ¿Qué es esto?

Tu aplicación **ProcesadorOCR** ahora está integrada con **DeepSeek R1: 8B**, un modelo de IA de última generación que se ejecuta localmente usando **Ollama**. Esto te da acceso a **IA empresarial completamente gratuita** para procesar documentos OCR.

## ✨ Características Principales

- **🆓 100% Gratuito** - Sin costos por uso, sin límites
- **🏠 Ejecución Local** - Tus datos nunca salen de tu computadora
- **🧠 IA Avanzada** - DeepSeek R1: 8B con 8 mil millones de parámetros
- **📄 Procesamiento Inteligente** - Extrae automáticamente campos faltantes del JSON
- **🔧 Fácil Configuración** - Scripts automáticos de instalación

## 🚀 Instalación Rápida

### 1. **Instalar Ollama**
```bash
# Descargar desde https://ollama.ai
# O usar el script automático
.\setup_deepseek_r1.ps1
```

### 2. **Descargar DeepSeek R1: 8B**
```bash
ollama pull deepseek-r1:8b
```

### 3. **Verificar Instalación**
```bash

# Debe mostrar: deepseek-r1:8b
```

## 📊 ¿Cómo Funciona?

### **Flujo de Procesamiento**
1. **📷 Documento** → Se escanea o se sube
2. **🔍 OCR** → Se extrae texto del documento
3. **⚙️ Procesamiento Inicial** → Se extraen campos básicos
4. **🤖 IA Post-Procesamiento** → **DeepSeek R1: 8B** completa campos faltantes
5. **✅ JSON Final** → Documento enriquecido con todos los campos

### **Ejemplo de Funcionamiento**
```json
// JSON INICIAL (con campos faltantes)
{
  "numeroFolio": "",
  "totalPagado": 0,
  "fechaVencimiento": ""
}

// TEXTO OCR
"COMPROBANTE N° 4560010758 TOTAL: $8.153.962 VENCIMIENTO: 09/07/2025"

// JSON FINAL (completado por DeepSeek R1: 8B)
{
  "numeroFolio": "4560010758",
  "totalPagado": 8153962,
  "fechaVencimiento": "2025-07-09T00:00:00"
}
```
